## Overview

The Grand Collection is a hospitality website for exploring guesthouses and the places around them. I developed the site and its content-management tools so guests can compare accommodation and continue to booking, while the business can update property information and publish articles.

- **Role:** Freelance web developer.
- **Dates:** November 2024–March 2025 (initial build).
- **Context:** Freelance client project, with ongoing maintenance and occasional updates.

## Technical contributions

### Designing the site around the business structure

With guesthouses in multiple locations, the site needed to help visitors find the right property and help search engines identify content relevant to each area.

- **Content management:** Linked properties, rooms, destinations and articles in Payload CMS so pages can be composed dynamically with content relevant to each property or destination.

### Image optimisation

The site was exhausting its Vercel image optimisation allowance, and the previous image setup lost cached versions on rebuilds. I addressed both by generating image variants during CMS upload and storing them independently of site deployments.

- **Upload processing:** Replaced the image-processing API with WebP variants generated during CMS upload, bypassing Vercel’s image optimisation service.
- **Persistent images:** Stored variants in Cloudflare R2 so site rebuilds can reuse them without regenerating each size.
- **Responsive delivery:** Connected the prepared sizes to responsive rendering, so browsers can load a suitable image without waiting for conversion.
- **Delivery trade-off:** Accepted additional upload processing and storage to simplify image delivery.

### Long-lived caching and targeted revalidation

Property information and articles can be served repeatedly between content updates. I used long-lived caching to make these visits faster and reduce server demand, with CMS changes triggering revalidation of the affected content.

- **Cache reuse:** Reused cached content across public requests, reducing repeated database queries while the content remains unchanged.
- **Targeted revalidation:** Connected CMS updates to revalidation of the affected pages or sections, allowing unrelated content to remain cached.
- **Visitor experience:** Allowed cached content to be served while updates refresh on subsequent requests, keeping the site responsive and limiting server work to the content that needs updating.

## Outcome

I delivered a hospitality website with tools for managing property information and articles, resolved its image optimisation limits, and reduced repeated database queries through caching.
