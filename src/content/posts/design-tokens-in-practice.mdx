# Design tokens in practice

Tokens translate design decisions into code. When they're clear and portable, you can ship consistent UI across products without manual overrides.

## Token categories

- Color tokens for semantic meaning.
- Spacing tokens for layout rhythm.
- Type tokens for clarity and hierarchy.

```json
{
  "color": {
    "brand": {
      "primary": "#4F46E5",
      "secondary": "#22C55E"
    }
  }
}
```
