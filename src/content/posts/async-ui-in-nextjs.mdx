Async boundaries are part of the design. Use them to show progression rather than a blank pause.

## Build around Suspense

```tsx
export default function Page() {
  return (
    <Suspense fallback={<div className="h-24 animate-pulse rounded-xl bg-white/5" />}>
      <Insights />
    </Suspense>
  )
}
```

## The experience matters

Progressive disclosure, skeletons, and staged reveals keep users oriented while data loads.
